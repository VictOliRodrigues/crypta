Boas Práticas

  • info

    Duração

    Toasts devem durar entre 3 a 5 segundos antes de desaparecerem automaticamente.

  • info

    Posicionamento

    No Desktop, aparecem no canto inferior direito. No Mobile, centralizados na base.

  • info

    Hierarquia Tonal

    Evite cores saturadas em excesso. Use bordas acentuadas (L-accent) para distinguir o estado.
