SENTINELA COMPLIANCE

Guia de Acessibilidade

Nosso compromisso é garantir que o Sentinela seja uma ferramenta de segurança de dados verdadeiramente inclusiva. Seguimos rigorosamente as diretrizes WCAG 2.1 para proporcionar uma experiência fluida para todos os usuários, independentemente de suas capacidades funcionais.
